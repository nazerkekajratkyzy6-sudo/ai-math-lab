# AI MATH LAB — AI математикалық зертханасы

«Жасанды интеллект математикалық есептерді қаншалықты дұрыс шығарады?» ғылыми жобасының интерактивті зерттеу платформасы
(автор: Ережепхан Ержігіт Бекзатұлы, 5 «Ғ» сынып; ғылыми жетекшісі: Токанова Назерке Оразбековна).

## Мүмкіндіктер

- **30 есеп – 30 тәжірибе** — есептер үш тәжірибеге бөлінген (№1–10, №11–20, №21–30); әр есеп: шарт → тіркелген AI жауабы → өз тексеруің → математикалық негіздеу (TypeScript-те нақты есептеу) → ғылыми жұмыстағы нәтиже.
- **ЖИ қатесін тап** — №14 есептің әр шартын жеке тексеру, 6 ретті тексеру, бүтін/бөлшек шешім туралы түсіндірме.
- **Математикалық модельдер** — 8 интерактивті модель (№22, №26, №20, №30, №21, №25, №18, №14).
- **Зерттеу нәтижелері** — үш тәжірибенің нәтижесі мен қорытындысы; кестелер мен диаграммалар 30 жазбадан автоматты есептеледі (10/10, 9/10, 10/10, 29/30, 96,7%).
- **PDF зерттеу есебі** — A4 PDF (jsPDF, DejaVu Sans қаріпі ендірілген, бет нөмірлері бар).
- **Жоба туралы** — ғылыми жұмыстың мәтіндері, күнделік, қорытынды.

## Технологиялар

React 18 + TypeScript + Vite 6, Tailwind CSS 3, KaTeX, Recharts, jsPDF + jspdf-autotable, react-router-dom.
Дерекқор, тіркелу, API кілттері және орта айнымалылары қажет емес.

## Жергілікті іске қосу

```bash
npm ci
npm run dev       # http://localhost:5173
npm run build     # нәтиже: dist/
npm run preview
```

Node.js 20 немесе одан жаңа нұсқасы қажет.

## GitHub + Vercel арқылы жариялау

1. GitHub-та жаңа репозиторий жасаңыз (мысалы, `ai-math-lab`).
2. Осы папкадағы барлық файлдарды репозиторийге жүктеңіз (`node_modules` және `dist` қажет емес).
3. Vercel → **Add New → Project → Import** → репозиторийді таңдаңыз.
4. **Framework Preset:** Vite.
5. **Build Command:** `npm run build`.
6. **Output Directory:** `dist`.
7. **Deploy** батырмасын басыңыз.

Репозиторий қосылғаннан кейін GitHub-тағы әр өзгеріс Vercel-де автоматты түрде қайта жиналады.
`vercel.json` ішкі беттерді (мысалы, `/esepter/14`, `/statistika`) тікелей ашқанда дұрыс жұмыс істеуі үшін SPA бағыттауын қамтамасыз етеді.

## Құрылымы

```
src/
  data/problems.ts     30 есеп: шарт, AI жауабы, дұрыс жауап, нәтиже, тексеру алгоритмі
  data/research.ts     ғылыми жұмыстың мәтіндері мен күнделігі
  data/experiments.ts  үш тәжірибе: сұрағы, әрекеттер, тексеру, қорытынды
  lib/stats.ts         статистиканы 30 жазбадан есептеу
  lib/pdf.ts           PDF есеп генераторы
  lib/fraction.ts      дәл бөлшек арифметикасы
  models/              8 интерактивті модель
  pages/               платформа бөлімдері
public/fonts/          PDF-ке арналған DejaVu Sans қаріпі (Kazakh/Cyrillic)
```
